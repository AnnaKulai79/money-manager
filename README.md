# 🛒 Shopping List Manager

Простий та ефективний консольний менеджер покупок, написаний на **Python**. Програма дозволяє вести облік витрат, групувати товари за датами та зберігати історію у файлі.

---

## 🌟 Основні функції

* **Додавання товарів:** Введення назви, кількості, ціни та дати з автоматичною перевіркою коректності формату.
* **Фільтрація та сортування:** Перегляд покупок на конкретну дату або повний список, відсортований за хронологією.
* **Фінансовий облік:** Автоматичний розрахунок загальної вартості всіх доданих товарів.
* **Робота з файлами:** * Збереження даних у локальний файл.
    * Завантаження існуючих списків із можливістю об'єднання даних.

---

## 🛠 Технічний стек

* **Мова:** Python 3.10+
* **Методи:** Обробка винятків (`try...except`), робота з файловою системою, використання сучасного оператора `match-case`.

---

## 📋 Інструкція з використання

1.  **Запуск:**
    ```bash
    python main.py
    ```
2.  **Формат дати:** Завжди використовуйте формат `дд-мм-рр` (наприклад, `25-12-25`).
3.  **Навігація:** Використовуйте головне меню (пункти 1-6) для вибору потрібної дії.

---

## 📂 Структура файлів

* `main.py` — основний логічний модуль програми.
* `data/Shopping_list.txt` — файл, у якому зберігаються ваші дані.
* `README.md` — документація проєкту.
